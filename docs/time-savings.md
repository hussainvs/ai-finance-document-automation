# Time-Saving Model (Estimate Only)

The assumptions below form a projection, not a verified performance result.

- Manual handling: 5–8 minutes per document; midpoint 6.5 minutes.
- Post-automation human handling: assumed 1 minute per document.
- Automation runtime: prior project note reported 8m 46s for a 25-document test effort. This was not verified as a single clean 25-document run.
- 100-document runtime: linear projection only, 4 × 8m 46s = 35m 4s.

| Metric | 100-document scenario |
|---|---:|
| Estimated manual handling at 6.5 min/document | 10h 50m |
| Assumed automation runtime | 35m 4s |
| Assumed human handling | 1h 40m |
| Estimated combined time | 2h 15m 4s |
| **Estimated time saved** | **8h 34m 56s (~8h 35m)** |
| Estimated reduction | 79.2% |

Range under the same runtime/human review assumptions: manual effort of 5 minutes/document gives roughly 6h 4m 56s saved (73.0% reduction); 8 minutes/document gives roughly 11h 4m 56s saved (83.1% reduction).

Measure actual manual and post-automation handling time on comparable documents before making a verified impact claim. The 100-document test itself has not been run.
